# Market Intel Dashboard

## Overview
Professional financial intelligence platform (Bloomberg Terminal lite) with real-time market data from Yahoo Finance, sentiment analysis, risk scoring, and technical indicators.

## Technical Architecture
- **Data Source**: Yahoo Finance via `yfinance` Python library (called via subprocess from Node.js API routes)
- **Python Script**: `/scripts/market_data.py` — handles all data fetching: ticker data, historical prices, analyst consensus, news, sentiment (momentum/volume/volatility/keyword), risk score (beta/IV rank/D/E), technicals (RSI/MACD), position sizing (Kelly Criterion), exit signals, macro indicators, ticker search
- **API Routes**: `/api/market/*` for data, `/api/watchlist/*` for CRUD (auth-protected), `/api/settings/apikeys` for optional API keys
- **Database**: Postgres with Prisma — User, Watchlist, ApiKey models
- **Auth**: NextAuth.js v4 with credentials provider

## Visual Style
- **Theme**: Dark mode only (#0a0a0f background)
- **Colors**: Green #00c853 (positive), Red #ff1744 (negative), Orange #ffa726 (warnings/neutral), Blue #60B5FF (info)
- **Typography**: DM Sans (body), Plus Jakarta Sans (headings), JetBrains Mono (numbers/data)
- **Layout**: Header with macro ribbon → ticker grid (main) → watchlist sidebar (right)
- **Charts**: Recharts for price/volume charts, custom SVG for RSI gauge

## Key Features
1. Macro ribbon (VIX, S&P 500, 10Y Treasury, Fed Funds, Market status)
2. Ticker search with autocomplete
3. Stock card grid with price, sentiment bar, risk badge
4. Detail modal: price chart, RSI/MACD technicals, exit alerts, analyst consensus, risk breakdown, Kelly position sizing, news with credibility tags, emerging trends
5. Persistent watchlist (DB-backed)
6. Optional API key settings (Alpha Vantage, Polygon.io)
7. 60-second auto-refresh for macro data

## Important Rules
- Never use "prediction", "guaranteed", "will rise/fall" — only "indicator", "signal", "suggests", "historically correlated"
- Every news headline shows source + credibility tag (High/Medium/Low)
